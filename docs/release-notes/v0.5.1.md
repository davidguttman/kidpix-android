**Tools remember what you picked.** Pick dynamite, switch to a brush, and come back to the eraser: it's still dynamite. Before, the eraser quietly went back to the plain eraser while dynamite still looked picked, so the page got rubbed out instead of blown up. Brushes keep your brush the same way, and stamps light up the stamp you really get.

**Install / update:** download `kidpix-android-0.5.1.apk` below and open it on the tablet. It updates the old version in place.
