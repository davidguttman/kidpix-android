**Kid Pix is now a native Android app.** Until now the app was a web page inside a browser window. This version is the same Kid Pix, rewritten to draw straight to the screen: every tool, option, sound, stamp and colour is there, in the same place, and makes the same picture.

- **Nothing to learn again.** The screen is laid out as before, to the pixel in most places. Scripted test drawings covering every option of every tool were compared with the old app's pictures: 327 of 328 differ in fewer than half a percent of their pixels, and the last one (the tree brush) in 0.6 percent.
- **Every tap counts.** The old app sometimes missed a button press made right after a stroke. This one doesn't.
- **A slow press is a press.** Holding a finger on a button for a moment now works like a tap. Before, it did nothing.
- **A faster pen where the tablet allows it.** On tablets that support it, pen strokes are drawn on a low-latency layer. The app measures both ways on the tablet and keeps the layer only if it is faster there.
- **No browser engine.** The app no longer depends on the tablet's WebView, so a WebView update can't change or break it.

Saved pictures stay where they are (`Pictures/Kid Pix`) and open in the new version.

**One thing to know before updating:** a drawing that is on the canvas but not saved is not carried over. Press Save in the old version first if you want to keep it.

**Not yet tried on a real tablet.** This version was tested on an emulator shaped like the Lenovo tablet, with simulated finger and pen input, and with the sound off. A real pen, a real palm, the low-latency layer and the sounds have not been checked on a device.

**Install / update:** open `kidpix-android-1.0.0.apk` on the tablet. It updates the old version in place.
